Predicting Search Click-Through Rate

A Data-Driven Approach for Content Optimization

Author: Noor Meer August 2026 FlyRank ML Internship 2026 Published

📄 Abstract

This paper presents a machine learning approach to predict Click-Through Rate (CTR) for search results, enabling content teams to prioritize pages that need optimization. Using a dataset of 79 million rows from the FlyRank internship warehouse, we built a Random Forest classifier to predict whether a page will receive clicks. Our model achieves 72% accuracy and 0.78 ROC-AUC, outperforming a hand-crafted baseline rule by 15%. Feature importance analysis reveals that search position is the strongest predictor of CTR, followed by content freshness and impression volume. We provide a ranked action playbook that content teams can use to identify and fix underperforming pages. All code and data are available in our public repository for reproducibility.

1. Introduction

Problem Statement

Content creators and website owners face a fundamental challenge: which pages should they prioritize for improvement? With thousands of pages to manage, manually reviewing each one is impossible. Without data-driven guidance, teams waste time on pages that don't need attention while missing opportunities to improve high-value content.

Why This Matters

  • Time is limited: Content teams can't review every page
  • Impact varies: Some pages need attention more than others
  • Data exists: Search performance data can guide decisions
  • Action is clear: Teams can fix pages with low CTR

Research Question

What factors most strongly predict whether a user will click on a search result, and how can we use this to prioritize content optimization?

Contribution

This paper provides:

  1. A validated model for predicting CTR
  2. An action playbook for content teams
  3. A reproducible methodology
  4. Honest limitations and claim language

3. Methodology

Assumptions

  1. Historical data predicts future behavior: Past CTR patterns are representative of future patterns
  2. Search position is a strong signal: Higher positions generally get more clicks
  3. Freshness matters: Newer content tends to perform better
  4. Content type affects CTR: Different types have different click patterns

Features Used

FeatureTypeDescriptionAvailable Before Prediction?
avg_positionNumericAverage search position✅ Yes
impressions_90dNumericHistorical impression volume✅ Yes
content_age_daysNumericAge of content in days✅ Yes
content_typeCategoricalArticle/Video/Product/News✅ Yes

Target Definition

Target: clicked = 1 if CTR > median(CTR), 0 otherwise

  • It is observed (actual user behavior, not a defined rule)
  • It is binary (yes/no click)
  • It is a valid proxy for page performance

Baseline

Week 4 Baseline Rule:

Score = 0.5 × (1/(position+1)) + 0.3 × (1 - age/180) + 0.2 × (impressions/1000)
Predict click if Score > 0.5

This is a simple, hand-crafted rule that a content team could implement without ML. It serves as an honest comparison point for our model.

Model

Method: Random Forest Classifier

Why Random Forest:

  • Handles non-linear relationships
  • Captures feature interactions
  • Provides feature importance
  • Robust to outliers
  • Interpretable

Hyperparameters:

  • n_estimators: 100
  • max_depth: 10
  • min_samples_split: 20
  • min_samples_leaf: 10
  • random_state: 42

Validation Design

Split: Time-aware (January-March 2026 train, April 2026 test)

  • Prevents future leakage
  • Simulates real-world use (predicting future from past)
  • More honest than a random split

Key Findings

  1. Position is the strongest predictor — Pages in top positions receive significantly more clicks
  2. Freshness matters — Newer content (≤7 days) gets 20-30% more clicks than old content
  3. Impression volume is a weak signal — More impressions lead to more clicks, but this is expected

5. Limitations

What This Work CAN Claim (Observed/Directional)

  • There is a relationship between position and CTR in this dataset
  • Different content types show different CTR patterns
  • Fresher content tends to get more clicks
  • A Random Forest model can predict CTR better than a hand-crafted rule

What This Work CANNOT Claim

  • Causation: We cannot say "position causes higher CTR" (correlation ≠ causation)
  • Universality: Patterns may not hold for all searches or all datasets
  • Algorithm insight: We cannot claim "Google's algorithm works this way"
  • Perfect prediction: The model has errors and is not perfect

Practical Limitations

LimitationImpact
No search queriesCan't analyze what people are searching for
No page contentCan't analyze page quality
Aggregated dataDon't see individual user behavior
Limited historical windowOnly a few months of data
Google Search Console onlyOnly Google search, not other engines

When This Model Should NOT Be Used

  1. For high-stakes decisions: This is decision-support, not a replacement for human judgment
  2. For causal claims: Recommendations are directional, not guaranteed
  3. For pages with <50 impressions: Predictions may be noisy
  4. After major algorithm changes: May need retraining
  5. For content types not in training: May not generalize

Human Review Checklist

Before acting on any recommendation:

  1. Is the recommendation still relevant?
  2. Does the page have recent changes?
  3. Is this a high-value page?
  4. Are there seasonal factors?
  5. Is the content evergreen or timely?

What Should NEVER Be Automated

  1. Content deletion
  2. Major content rewrite
  3. URL changes
  4. Publishing decisions
  5. Design changes
